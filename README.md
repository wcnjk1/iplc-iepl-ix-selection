## 先分清三个词：IPLC、IEPL、IX

这三个词经常被商家混着用，但对应的产品形态不一样。

**IPLC 和 IEPL** 是传统意义上的"物理专线"：跨境段走运营商专属线路，不经过公网。Mkcloud 的 IPLC 产品从上海电信或上海 BGP 入口出发，IEPL 产品从广州多个入口出发，入口到出口的端内延迟是确定的，比如广港 1~2ms、沪港 21ms、沪日 25~28ms、沪美 124~134ms。

**IX**（互联网交换中心接入）是另一条路：你需要先有一台阿里云、腾讯云这类云厂商的服务器作为"前置"，通过云厂内网接入 Mkcloud 的交换节点再出海。它不限制连入省份，但前置云机本身要花钱，而且必须在支持的云厂范围内——比如深圳入口目前支持腾讯云、百度云国内全网和火山云、华为云华南，阿里云国内全网暂时不通。

还有一种容易混淆的产品是**上海 CN2**：它是国内优化线路（上海动态联通入口、上海电信 CN2 出口），不出境。不少人冲着"CN2"三个字以为买到了美国 CN2 GIA，其实完全不是一回事，官网自己也专门澄清过。它是给需要国内出站质量场景准备的，别当海外节点买。

## 一台专线 VPS 实际是什么形态

Mkcloud 每台 VPS 分配两个独立 IP：**入口 IP** 给你远程连接用（Windows 走 RDP，Linux 走 SSH），**出口 IP** 是业务流量实际对外的身份。你在 VPS 里开浏览器、跑脚本、调 API，流量自动从出口 IP 出去。

这个"单端双 IP"结构决定了产品的边界：**出口不接受外部连入**。你不能拿它建公开网站、收支付回调、收邮件，也不能跑对外游戏服务端。业务程序必须运行在 VPS 内部，而不是"本地电脑挂个代理"——连上远程桌面，不代表你本地所有软件都自动走专线。

## 共享还是独享：两种计费方式的区别

Mkcloud 把套餐分成两类，对应两种完全不同的评估方法：

| 维度 | 流量计费（共享带宽） | 带宽计费（独享带宽） |
| --- | --- | --- |
| 带宽含义 | 峰值速率，不保证持续跑满 | 固定独享速率，可长时间持续 |
| 流量 | 按月额度，**上下行双向统计** | 不限流量 |
| 适合 | 间歇性操作后台、上传素材 | 直播推流、持续传输、大文件同步 |
| 超量后 | 暂停，可购买流量重置或工单升级 | 无此问题 |

注意"双向统计"这一条：计量型套餐里上传和下载都算流量，实际用量大约是你以为的两倍。共享和独享也不能直接比数字——200Mbps 共享峰值和 5Mbps 独享是两种东西，前者看突发，后者看持续。

## 付款前必须确认的六条规则

这部分是官网产品页原文要求，每一笔订单都会再确认一次，但很多人根本没往下读：

1. **实名认证**：需要中国身份信息，仅限个人或企业正规用途，禁止机场、回国等违规用途。
2. **省级白名单**：直连款只允许一个绑定省份的 IP 连入（可自行切换省份），这是防滥用的硬措施。人在多地或团队异地办公的，先确认主力连入地点。
3. **退款政策**：仅支持质量问题退款，且需要提交具体延迟、速度数据作为证据；开通后不支持更换到其他地域。
4. **双向流量**：计量型套餐上下行都计入流量，超量即停机。
5. **无备份能力**：产品不提供快照和备份，重要数据自己安排。升降级走工单，降级差价不退。
6. **SLA 缺省**：默认没有可用性赔付承诺，只能通过工单另行协商。

## 购买与开通流程

从下单到能用，实际就五步：

1. 在商店选地区（出口方向）→ 选网络（入口）→ 选类型（共享/独享）→ 选套餐档位。
2. 选操作系统（Ubuntu、Debian、AlmaLinux、Rocky、CentOS 等十余种可选），直连款在附加选项里绑定可连入省份。
3. 完成实名认证并支付。现货产品口径约 1 分钟自动开通，实际受支付和库存影响。
4. 用开通信息里的入口 IP 和账号密码连接：Windows 走远程桌面，Linux 走 SSH。
5. 在 VPS 内安装业务程序，核对实际出口 IP 和目标服务的响应情况。

开通后建议先做两件事：用 ping/mtr 看入口到 VPS 的连接质量；再跑一遍有代表性的业务操作，确认出口到目标平台的路径符合预期。官方明确提醒：ping 数据不能证明全程物理专线质量，测速需要自己的服务端和流量预算。

## 常见问题

**能拿来建站吗？** 不能。出口 IP 不接受外部连入，公开网站、支付回调、邮件接收都需要支持入站的产品。

**是原生 IP、能解锁流媒体吗？** 官方明确不保证原生、住宅或流媒体解锁属性，也不要指望独享 IP 能保证账号一定不被平台限制。

**能替代办公室组网吗？** 不能。它交付的是 VPS，不负责把你办公室、机房和云组成专用网络。

**超量停机了怎么办？** 自助购买流量重置，或提交工单补差价升级，两种方式都在后台可操作。

**上海 CN2 是出海节点吗？** 不是，它是上海进上海出的国内优化产品，只是 CN2 这个名字容易让人误会。
